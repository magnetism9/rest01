### 2-7. 컬러 테마 시스템 + 다크모드 `3ba024c`

CSS Custom Property 기반의 5-테마 시스템을 설계·구현하였다.

**테마 파일 구조**
```
css/themes/
├── theme-purple.css  — 다크퍼플 / 옐로우  (기본)
├── theme-blue.css    — 다크블루 / 로열블루
├── theme-green.css   — 다크그린 / 연두
├── theme-rose.css    — 다크로즈 / 코랄핑크
└── theme-teal.css    — 다크틸  / 민트시안
```

**각 테마 파일 변수 구성**
- 라이트 모드 `:root` 변수
- 시스템 다크모드 `@media (prefers-color-scheme: dark)`
- 수동 다크모드 `[data-mode="dark"]`
- 수동 라이트모드 `[data-mode="light"]`

**팔레트 스위처 UI**
- 우측 하단 고정 위젯 (`position: fixed`)
- 🎨 버튼 클릭 시 5개 스와치 패널 오픈
- 🌙 버튼으로 라이트/다크 수동 전환
- `localStorage` 선택 상태 영구 저장

**접근성 적용**
- 모든 버튼 `aria-label`, `aria-expanded` 속성
- ESC 키로 패널 닫기
- `:focus-visible` 포커스 링 (`outline: 3px solid var(--c-accent)`)
- WCAG 대비비: 주요 텍스트-배경 **4.5:1 이상** 확보
